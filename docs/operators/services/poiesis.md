# Poiesis

[Poiesis](https://github.com/JaeAeich/poiesis) is a GA4GH Task Execution
Service (TES) implementation for Kubernetes, next to [TESK](tesk.md) and
[Funnel](funnel.md). See its repository for how to install and configure it.

!!! warning "Under construction"
    How Poiesis fits into the ELIXIR On-Cloud deployment is not documented yet
    (see issue #64).

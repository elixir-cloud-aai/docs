# DRS-Filer

!!! warning "Archived"
    The [DRS-Filer](https://github.com/elixir-cloud-aai/drs-filer)
    repository was archived on 2026-11-15 and is no longer maintained. Don't deploy DRS-Filer for the ELIXIR On-Cloud; this page
    is kept for reference.

[DRS-Filer](https://github.com/elixir-cloud-aai/drs-filer) is a lightweight
implementation of the [GA4GH DRS][ga4gh-drs] API. It serves data objects.

## Role in the deployment

DRS-Filer was the DRS implementation of the ELIXIR On-Cloud project.
